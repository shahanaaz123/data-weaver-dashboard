# Data Weaver Dashboard

## 📊 Project Overview
This dashboard visualizes the relationship between two unrelated datasets:
- Weather temperature data
- Food order volume data

The goal is to explore patterns and insights by mashing up datasets in a simple, interactive way.

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- Chart.js

## 🚀 Features
- Line chart visualization
- Two datasets displayed together
- Responsive and lightweight web dashboard
