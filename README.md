# Weather vs Food Orders Dashboard

## 📌 Description
This project visualizes the relationship between weather conditions and food ordering patterns using interactive charts.

## 🚀 Features
- Line chart comparing temperature and food orders
- Bar chart showing order distribution
- Responsive UI with modern design

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript


## 📊 Use Case
Helps businesses understand how weather impacts customer behavior.
